AI SSH Assistant · 界面设计方案UI Designer（像素君）出品 · 暗色优先 / WCAG AA / 三栏终端工作台

设计定位：终端是主角，AI 是副驾，风险是一眼可辨的红绿灯。整个方案围绕 SSH 运维用户的核心习惯构建——信息密度高、键盘优先、暗色护眼、危险操作必须有摩擦。

一、设计原则

原则落地方式
终端即主角终端区占据最大面积（≥55%），侧栏均可折叠；AI 元素统一用紫色系标识，与终端的蓝/绿提示区分，避免视觉抢夺
风险三色语言绿=安全只读 / 黄=需确认 / 红=高危拦截，全应用（错误色条、诊断卡片、确认弹窗）复用同一套颜色语义，形成肌肉记忆
失败有出口每个失败状态（API 失败、解析降级、密钥不匹配）都伴随明确的下一步动作按钮，界面无死胡同
键盘与效率# 前缀即进入 AI 模式；Ctrl+1/2/3 聚焦三栏；Ctrl+Enter 触发分析；Esc 关闭弹层回到终端

五、交互规格清单（实现对照）

场景交互设计对应状态机

七、可访问性与落地说明

项规格
对比度全部正文 ≥ 4.5:1、大字号/图标 ≥ 3:1（WCAG AA）；风险色不得作为唯一区分手段，必须伴随文字标签（如「高危」）
触达目标所有按钮/行项命中区 ≥ 32×32px；输入行高度 42px
键盘导航Tab 顺序：主机列表 → 终端 → AI 卡片 → 输入行；焦点环 2px 品牌蓝永不隐藏
动效克制仅卡片淡入（150ms）与光标闪烁两处动效；尊重系统「减少动态效果」设置
落地方式令牌对应 src/styles.css 的 CSS 变量替换；组件结构与现有 React 组件一一对应（Topbar/HostList/TerminalPane/AiSidebar/Dialogs），可渐进式改造，无需推翻重写
